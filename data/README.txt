========================================
数据文件夹结构说明
========================================

本文件夹包含预处理后的数据，用于水下多模态时序预测模型训练。

----------------------------------------
1. 文件夹结构
----------------------------------------

data/
├── README.txt              # 本说明文件
├── statistics.json         # 归一化统计信息（均值、标准差、最小值、最大值）
├── split_indices.json      # 数据集划分索引（train/val/test）
└── processed/              # 预处理后的序列数据
    ├── train/              # 训练集 (2655个序列, ~70%)
    │   ├── seq_00000.npz
    │   ├── seq_00001.npz
    │   └── ...
    ├── val/                # 验证集 (550个序列, ~15%)
    │   ├── seq_00000.npz
    │   └── ...
    └── test/               # 测试集 (551个序列, ~15%)
        ├── seq_00000.npz
        └── ...

----------------------------------------
2. 文件说明
----------------------------------------

statistics.json:
  - 包含训练集的归一化统计信息
  - 用于对navigation数据进行标准化和反标准化
  - 包含字段: mean, std, min, max, n_samples

split_indices.json:
  - 记录了train/val/test的序列索引
  - 确保数据划分的可重现性

processed/train|val|test/seq_XXXXX.npz:
  - 每个.npz文件包含一个完整的输入-输出序列对
  - 包含以下数组:
    * camera: [20, 3, 224, 224]  - Camera图像序列（20帧）
    * sonar: [20, 3, 320, 320]   - Sonar图像序列（20帧）
    * navigation: [20, 10]       - Navigation数据序列（20个时间步）
    * target: [5, 10]            - 预测目标（未来5个时间步）
    * indices: [25]              - 原始数据索引（20输入+5输出）

----------------------------------------
3. 数据维度说明
----------------------------------------

Camera图像:
  - 原始分辨率: 640x480
  - 预处理后: 224x224 (ResNet18输入尺寸)
  - 通道顺序: RGB
  - 数值范围: [0, 1] (已归一化)

Sonar图像:
  - 原始分辨率: 640x480
  - ROI裁剪: [293:497, 296:637] (捕获完整声纳扇形)
  - 预处理后: 320x320
  - 通道顺序: RGB
  - 数值范围: [0, 1] (已归一化)

Navigation数据 (10个参数):
  - 0: latitude        (纬度, 度)
  - 1: longitude       (经度, 度)
  - 2: depth           (深度, 米)
  - 3: yaw             (偏航角, 弧度)
  - 4: pitch           (俯仰角, 弧度)
  - 5: roll            (横滚角, 弧度)
  - 6: velocity_x      (X轴速度, m/s)
  - 7: velocity_y      (Y轴速度, m/s)
  - 8: velocity_z      (Z轴速度, m/s)
  - 9: altitude        (高度, 米)

归一化策略:
  - latitude, longitude: Min-Max归一化 [0, 1]
  - depth, altitude: Min-Max归一化 [0, 1]
  - yaw, pitch, roll: Min-Max归一化 [-1, 1]
  - velocity_x, velocity_y, velocity_z: Z-score标准化

----------------------------------------
4. 序列构建说明
----------------------------------------

时间窗口:
  - 输入序列长度 (seq_length): 20个历史帧
  - 预测时长 (pred_horizon): 5个未来帧
  - 总计: 25个连续时间步

滑动窗口:
  - 步长: 1 (即每次滑动1帧)
  - 从原始3828个样本生成3756个有效序列

数据划分:
  - 训练集: 70% (2655个序列)
  - 验证集: 15% (550个序列)
  - 测试集: 15% (551个序列)

----------------------------------------
5. 数据加载
----------------------------------------

代码会自动从processed/train|val|test/读取.npz文件，
无需手动处理本说明文件。

使用PyTorch DataLoader:
  - 见 src/dataset.py 中的 UnderwaterSequenceDataset 类
  - 自动加载对应split的所有seq_*.npz文件

----------------------------------------
6. 注意事项
----------------------------------------

- 请勿删除或修改 statistics.json 和 split_indices.json
- 请勿手动修改 processed/ 文件夹中的 .npz 文件
- 本README.txt不会影响数据加载流程
- 如需重新预处理，运行 python preprocess.py
